# 📚 SMARTLIBRARY – Smart Library Management System

SMARTLIBRARY is a digital library management system designed to simplify seat allocation and book management in a library. The system provides **role-based access** for **Admins** and **Students**, ensuring smooth and controlled library operations.

---

## 🚀 Features

### 👤 User Roles
The system has **two login options**:
- **Admin**
- **Student**

---

### 🔐 Admin Features
Admins have complete control over the library system:
- Allocate library **seats** to students
- Issue and manage **books** for students
- View all **issued books and seat assignments**
- Set and manage **due dates** for borrowed books

---

### 🎓 Student Features
Students have limited, view-only access:
- View **available seats** in the library
- View **available books**
- Check **borrowed books**
- View **due dates** of borrowed books

## 🧩 System Workflow
1. User logs in as **Admin** or **Student**
2. Admin manages seats and books
3. Students can only view availability and their own records
4. Due dates help track book returns efficiently

## 🎯 Use Case
SMARTLIBRARY is ideal for:
- College libraries
- University reading rooms
- Study halls with seat reservation systems
